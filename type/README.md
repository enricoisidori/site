# Type Disorder

Questa è la versione con impostazioni e preset salvati in `presets.json` nella stessa cartella.

Apri un terminale nella cartella `type` e avvia:

```sh
node server.js
```

Poi apri [http://127.0.0.1:4177/](http://127.0.0.1:4177/).

Ogni modifica aggiorna `current` in `presets.json`. Con **Salva preset con questo nome** crei o aggiorni un preset nominato; dal menu sottostante puoi caricarlo. Il server ascolta solo su `127.0.0.1` e non richiede dipendenze esterne. Google Fonts richiede una connessione.
